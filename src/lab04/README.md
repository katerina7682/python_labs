<h1>ЛР4 — Файлы: TXT/CSV и отчёты по текстовой статистике</h1>

<h2>Задание A - io_txt_csv.py</h2>  

Реализован модуль для чтения текстовых файлов и записи результатов в CSV. Для работы с путями используется Path, а для формирования CSV — стандартный модуль csv.  

<h3>Функции:</h3>  

<h3>1. Функция read_text</h3>    

Функция читает текстовый файл целиком в указанной кодировке (по умолчанию utf-8)  
Если файл не найден, возникает FileNotFoundError. При несовпадении кодировки возникает UnicodeDecodeError.  

<h3>2. Функция write_csv:</h3>  

Функция записывает строки в CSV-файл. Перед записью проверяется, что все строки имеют одинаковую длину. Если длины отличаются, вызывается 9ValueError.  
Если передан параметр header, он записывается первой строкой файла.

<h3>Краевые случаи</h3>   

- Пустой файл → возвращается пустая строка.   
- Файл очень большой → допускается читать целиком (наше ТЗ), но в README отметить, что в реале стоит читать построчно.    
- write_csv с пустым rows и header=None → создаётся пустой файл (0 строк). С header=("a","b") → файл содержит только заголовок.   

<h2>Задание B - скрипт статистики text_report.py</h2>  
Скрипт читает текстовые файлы, использует функции normalize, tokenize, count_freq и top_n из лабораторной работы №3, сохраняет частоты слов в CSV-файлы.
